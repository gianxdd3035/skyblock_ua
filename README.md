# SkyBlock UA

Клієнтський Fabric-мод, який перекладає Hypixel SkyBlock українською: назви й описи предметів, заголовки меню, повідомлення сервера й діалоги NPC.
Перекладає офлайн, за вбудованим словником. Нічого не надсилає в інтернет і нічого не змінює в тому, що йде на сервер.

Minecraft **26.2**, Fabric Loader 0.19.5+, Fabric API, Java 25.

> Код і переклад зроблено з допомогою Claude (Anthropic).

## Що вже перекладається (версія 0.5)

- рідкість і тип предмета (`LEGENDARY SWORD` → `ЛЕГЕНДАРНИЙ МЕЧ`), з узгодженням роду;
- стати й підписи (`Strength: +50 (+10)` → `Сила: +50 (+10)`), числа й кольори зберігаються;
- найчастіші рядки описів (за базою NEU це ~66% усіх рядків описів);
- назви зачарувань (155), у тому числі в списках Skyblocker (`Sharpness VI→VII`) і в тегах Iconographic;
- назви здібностей і бонусів (~380): `Ability: Wither Impact` → `Здібність: Удар візера`;
- кольори: якщо в перекладі не задано §-кодів, числа, значки статів (❤ ❣ ☘) з назвою стату
  й перенесені англійські слова лишаються свого кольору, як в оригіналі;
- імена NPC (~500) у чаті («[NPC] Джейкоб:»), над головами й у меню: посади перекладено
  («Адміністраторка сафарі», «Банкір Баррі»), власні імена транслітеровано, каламбури — з українським приколом
  («Феєлософ», «Страхоторговець»); вимикається `/ukr npc`;
- типові рядки бонусів зі статом: `Grants +50 ❁ Strength.` → `Дає +50 ❁ сили.` (назва стату в родовому відмінку);
- сумісність із модами, що змінюють чат своїми шрифтами чи RGB-кольорами (наприклад, Feesh): імена й числа,
  які переклад не змінює, лишаються з усім своїм оформленням;
- заголовки меню-шляхів (`Bestiary ➜ Spider's Den` → `Бестіарій ➜ Павуче лігво`), номери сторінок `(1/3)`;
- назви: матеріали, зачаровані матеріали, міньйони, 136 сетів броні, популярна зброя й інструменти;
- рефоржі, узгоджені з родом предмета: `Ancient Necron's Boots` → `Стародавні чоботи Некрона`,
  `Fierce Molten Necklace` → `Люте розплавлене намисто`, разом з позначкою Shiny: `Shiny Heroic Hyperion` → `Сяючий героїчний Гіперіон`;
- рядки від інших модів у тултіпах (ціни NPC/аукціону/базару, Museum, Est. Item Value);
- повідомлення сервера в чаті: за твоїми логами гри перекладається ~80% усіх повідомлень;
- ~200 реплік NPC (Джейкоб, Сіріус, відвідувачі Саду, конкурси тощо);
- основні меню й кнопки, «ПКМ/ЛКМ» замість RIGHT CLICK/LEFT CLICK у здібностях.

Чого поки немає: скорборд праворуч, таб-лист, імена мобів над головами, описи зачарувань, більшість аксесуарів.
Якщо назву предмета не знайдено в словнику, вона лишається англійською цілком, разом із рефоржем,
щоб не виходило напівперекладене «Лютий Unknown Sword».

## Сумісність з Iconographic

Iconographic будує свій тултіп з іконками, розбираючи англійський текст рядків. Тому, якщо він встановлений,
SkyBlock UA не змінює рядки заздалегідь, а підставляє переклад лише під час малювання.
Iconographic бачить англійський оригінал і ставить свої іконки, а на екрані текст український.
Те саме з іншими модами (SkyHanni, Skyblocker): вони читають предмети й чат в оригіналі.

Теги зачарувань Iconographic будуються навколо назви (фон підганяється під її ширину), тому назву
зачарування мод підміняє ще до побудови тегу. Опція Iconographic «дрібний текст зачарувань» використовує
піксельний шрифт лише з латиницею, тож поки переклад увімкнений, теги малюються звичайним шрифтом.

## Встановлення

1. Збери мод (див. нижче) або візьми готовий `.jar`.
2. Поклади `skyblock-ua-0.5.0+mc26.2.jar` у `.minecraft/mods` разом із Fabric API.
3. Заходь на Hypixel. Переклад працює тільки там (вимикається командою `/ukr hypixel`).

## Керування

| Що | Як |
|---|---|
| Увімкнути/вимкнути переклад | клавіша **U** або `/ukr toggle` |
| Стан мода | `/ukr` |
| Назви предметів (вимкни для пошуку в Аукціоні/Базарі) | `/ukr names` |
| Описи, чат, меню окремо | `/ukr lore`, `/ukr chat`, `/ukr titles` |
| Імена NPC (англійські, коли шукаєш NPC за гайдом) | `/ukr npc` |
| Перечитати словники | `/ukr reload` |
| Зберегти неперекладені рядки у файл (у чаті з'являться посилання «Відкрити файл» / «Відкрити папку») | `/ukr dump` |

Налаштування лежать у `.minecraft/config/skyblockua/config.json`.

## Як доповнювати переклад

Мод запам'ятовує кожен рядок, якого немає в словнику (крім чату інших гравців).
Коли відкрите будь-яке меню, мод раз на секунду сам читає назви й описи всіх предметів у ньому
(прямо з даних предмета, без участі інших модів),
тож наводити на кожен предмет не треба. Файл зберігається сам кожні 2 хвилини (якщо з'явилося нове)
і під час виходу з гри.

1. Пограй, повідкривай потрібні меню.
2. Файл `.minecraft/config/skyblockua/missing.tsv` (від найчастіших рядків до найрідших) уже лежить у папці. `/ukr dump` зберігає його негайно й дає посилання.
3. Переклади рядки й поклади їх у `.minecraft/config/skyblockua/dict/мій_переклад.tsv` або додай у вбудований словник `src/main/resources/assets/skyblockua/dict/`.
4. `/ukr reload`.

Формат словника: UTF-8, кожен рядок `англійською<TAB>українською`.
- Числа в англійській частині пиши як `{0}`, `{1}`, а в перекладі став ті самі `{0}`, `{1}`.
- Кольори в перекладі задаються §-кодами (`§7` сірий, `§a` зелений, `§c` червоний, `§l` жирний). Якщо кодів немає, рядок бере колір оригіналу.
- Назва файлу задає розділ:
  - `names*.tsv`: назви предметів. Третій стовпець (необов'язковий) задає рід `m/f/n/p`, від нього залежить форма рефоржу. Якщо його немає, рід визначається за першим словом перекладу.
  - `armor_pieces.tsv` / `armor_sets.tsv`: частини броні та сети. Назва складається сама: `Шолом` + `Вищого Дракона`, або `adj:Алмазний` + `шолом` → `Алмазний шолом`.
  - `reforges.tsv`: рефорж і 4 форми (ч, ж, с, мн). Генерується з `tools/gen_reforges.py`.
  - `patterns*.tsv`: шаблони з підстановками `{item}` (назва предмета, перекладається) та `{any}` (ім'я, лишається як є).
  - `npcs*.tsv`: імена NPC (порівнюються дослівно).
  - `stats*.tsv`: назви статів у родовому відмінку для підстановки `{stat}` у шаблонах (`Grants {0}{stat}.` → `Дає {0}{stat}.`).
    Якщо стату немає в словнику, шаблон не спрацьовує.
  - `labels*.tsv`: підписи перед двокрапкою. `tokens*.tsv`: слова, що замінюються будь-де. Решта файлів містять цілі рядки.
- Новий вбудований файл треба дописати в `dict/index.txt`.

## Збірка

Найпростіше через IntelliJ IDEA: File → Open → папка проєкту, дочекатися імпорту Gradle, далі вкладка Gradle → Tasks → build → **build**.
Або в терміналі в папці проєкту:

```
gradlew build
```

Готовий файл з'явиться в `build/libs/`. JDK 25 Gradle завантажить сам.

## Як це влаштовано

- `core/` — рушій перекладу без залежності від Minecraft:
  - `Template` замінює числа на `{0}`, `{1}`, тож один запис покриває всі варіанти з різними числами;
  - `Translator` перебирає правила: цілий рядок → шаблон із підстановками → рядок без «прикрас» (зірки, рефорж, `[Lvl N]`, римські рівні) → чат (лічильник повторів, капсовий префікс, діалог NPC) → підпис перед двокрапкою й токени → по шматках (тільки чат);
  - `UaGender` визначає рід і ставить прикметник у потрібну форму;
  - `Lines` замінює частину рядка, зберігаючи кольори решти.
- `mixin/ItemStackMixin` підміняє готові рядки тултіпа. Сам предмет не змінюється, тому SkyHanni, Skyblocker тощо читають оригінал.
- `mixin/ContainerScreenMixin` перекладає заголовок меню лише під час малювання. Інші моди впізнають меню саме за англійською назвою.
- `mixin/ClientTextTooltipMixin` і `mixin/compat/*` перекладають рядки тултіпа лише під час малювання (для сумісності з Iconographic).
- Чат перекладається вже після того, як повідомлення потрапило в історію, тож інші моди встигають прочитати англійський текст.

Перевірити рушій без Minecraft (потрібен JDK 21+):

```
tools/run-engine-test.sh [шлях до NotEnoughUpdates-REPO/items]
python3 tools/check_dict.py
```
